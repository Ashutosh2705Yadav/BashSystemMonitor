📊 Bash System Monitor

A lightweight and fast system monitoring tool built using Bash scripting. It provides real-time insights into CPU, memory, disk usage, and running processes directly in the terminal.

🚀 Features
	•	Real-time CPU usage
	•	Memory (RAM) monitoring
	•	Disk space tracking
	•	Active processes overview
	•	Minimal and efficient (no GUI required)
	•	Easy to customize

🛠️ Tech Stack
	•	Bash
	•	Linux CLI tools: top, free, df, ps

📦 Installation & Usage

git clone https://github.com/your-username/bash-system-monitor.git
cd bash-system-monitor
chmod +x monitor.sh
./monitor.sh

📸 Sample Output

CPU Usage: 25%
Memory Usage: 3.2GB / 8GB
Disk Usage: 40%
Top Processes:
1. chrome
2. node
3. bash
